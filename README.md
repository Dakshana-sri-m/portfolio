- **Typography**: DM Serif Display, Inter, and JetBrains Mono
- **Interactive Features**: 20-Week ProtoSem Sprint Engine, Case Studies, Capability Matrix, Verified Proof Records (ICCSAM 2026, Mahatma Gandhi Merit Scholarship), and Client-Side Edit Mode with LocalStorage and JSON Import/Export.
